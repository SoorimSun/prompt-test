편차와 주의

벤치마크 스킬의 정식 절차와 다르게 진행한 부분을 모두 적었습니다. 이 항목은 다른 모델과 비교할 때 함께 봐야 합니다.

  1. 폴더 이름. 요청한 haiku-5.5는 정식 모델 ID claude-haiku-5-5와 다릅니다. 그래서 스킬 스크립트의 자동 대조(모델 ID와 폴더 이름 일치 확인)를 통과하지 않습니다. 실행 모델은 세션 기록의 모델 ID로 따로 확인했습니다.
  2. 폴더 생성. prepare_run.py를 쓰지 않고 mkdir로 만들었습니다. 생성 시각은 15:51:17 KST로, 조사·설계가 끝난 뒤입니다. 결과 폴더는 같습니다.
  3. 다른 모델 페이지 확인. 설계 단계에서 다른 Alice 페이지 4개(space-bunny-free, longcat-2.5-preview-free, opus-5.5, sonnet-5.5)의 <title>, 제목 클래스, font-family 줄을 grep으로 확인했습니다. 목적은 겹치는 디자인을 피하는 것이었고, 레이아웃이나 코드는 복사하지 않았습니다. 그래도 스킬의 "다른 모델 페이지를 디자인 참조로 쓰지 않음" 규칙에서 벗어난 부분이므로 편차로 기록합니다. longcat-2.5-preview-free의 .gitattributes 한 개도 확인했습니다.
  4. 측정 도구. extract_metrics.py는 Codex 세션 기록 전용이라 실행하지 않았습니다. 같은 정의로 Claude Code 세션 기록을 직접 집계했습니다. 이전 longcat, space-bunny-free 측정도 스킬 스크립트가 아닌 세션 저장소를 같은 스키마로 옮겨 집계했습니다.
  5. 키보드·마우스 검증 시점. 페이지 작업 중에는 키보드 조작을 검증하지 않았습니다. 해당 점검은 보고서 단계에서 따로 수행했고 측정에는 넣지 않았습니다.
  6. 실행 환경 차이. 세션 시작 훅이 superpowers 스킬 안내를 주입했고, 사용 가능한 스킬 목록이 길었습니다. 권한 모드는 bypassPermissions였습니다. 다른 실행 환경(opencode, Codex)과는 다릅니다.
  7. advisor 메타데이터. 세션 기록의 advisorModel 필드에 claude-opus-5-5이 적혀 있습니다. 하지만 이 구간에서 advisor 도구 호출은 0회였고, Haiku 외 모델의 호출도 0회였습니다. 따라서 이 작업은 전부 Haiku 5.5의 작업으로 봅니다.
  8. 임시 파일 위치. 글꼴 URL 확인용 임시 파일 한 개를 /tmp에 저장했습니다. 시스템 지침은 세션 scratchpad 사용을 권장합니다. 페이지 산출물에는 영향이 없습니다.
  9. 검증 스크립트 결함. 칸 위치 계산식에서 변수를 정의하지 않아 칸 스크린샷이 히어로 상태로 찍혔고, 리로드 후 스크롤 위치 복원을 고려하지 않아 모바일 히어로 스크린샷이 칸 V로 찍혔습니다. 이 둘은 페이지 결함이 아니라 검증 도구의 결함이었고, 고친 뒤 다시 실행했습니다.

생성 결과 설명

콘셉트. 체스판의 졸(폰)인 앨리스가 여덟 번째 칸에 닿아 여왕이 되는 원작 구조를 페이지의 뼈대로 삼았습니다. 상단의 여덟 칸 막대가 목차이자 진행 표시이며, 졸 말이 칸을 건너갑니다. 시그니처는 히어로의 거울 렌즈입니다. 렌즈 안에서만 세계가 좌우 반전되어 글자가 거울 글씨가 되고, 포인터가 없으면 렌즈가 제목 위를 천천히 떠다닙니다.

연출 흐름

  • 스크롤 진행률에 따라 페이지 아래쪽이 붉게 데워집니다(#warm). 마지막 칸에서 가장 진해집니다.
  • 칸에 들어서면 요소가 아래에서 떠오르며 나타납니다. 현재 칸은 칸 막대에서 표시됩니다.
  • 졸 말은 칸을 옮길 때 깡충 뜁니다(Web Animations API). 칸 VIII에서는 졸 말이 여왕 말로 바뀝니다.

기술 구현

  • 구성. 단일 HTML 파일입니다. CSS와 JavaScript는 모두 파일 안에 있고, 외부 의존은 Google Fonts 한 개뿐입니다. 빌드 단계는 없습니다.
  • 거울 렌즈. 히어로 내용을 복제해 좌우 반전 레이어를 만들고, 원형 clip-path로 렌즈 안쪽만 보여 줍니다. 반전 축은 렌즈의 중심입니다(x → 2·렌즈x − x). 렌즈 테두리는 별도 요소입니다.
  • 체스판 바닥. conic-gradient로 체크 무늬를 만들고 rotateX(72deg)와 원근 변환으로 기울였습니다.
  • 입자. Canvas 2D로 금빛과 서리빛 먼지를 그립니다(화면 크기에 따라 최대 110개). 폭발 입자는 최대 700개까지 허용합니다.
  • 관찰자와 이벤트. IntersectionObserver 두 개(현재 칸 추적과 등장 연출), 스크롤 리스너 한 개(requestAnimationFrame으로 묶음)를 씁니다.
  • SVG. 말, 꽃, 왕관은 symbol과 use로 재사용합니다. SVG 요소 17개와 use 참조 42개가 있습니다(정의 영역, 칸 막대의 말, 장식 그림, 별 여섯 개 포함).
  • 동작 줄이기. prefers-reduced-motion에서는 애니메이션 시간을 0.01ms로 줄이고, 렌즈와 입자를 멈추고, 눈송이를 없앱니다.
  • 줄바꿈. text-wrap: balance와 pretty로 한 글자짜리 줄(고아 글자)을 줄였습니다. 지원하지 않는 브라우저에서는 일반 줄바꿈이 됩니다.

접근성과 반응형

  • lang="ko", h1 한 개, 칸마다 h2 한 개입니다. 장식 요소는 aria-hidden으로 숨겼습니다.
  • 칸 버튼에 aria-label과 aria-current="step"을 달았습니다. 포커스 링은 금색 2px 테두리입니다.
  • 760px 이하에서는 한 열로 바뀌고, 그림이 글 위에 옵니다. 가로 넘침은 390px에서도 없습니다.

콘텐츠 출처와 번역 주의

원작은 루이스 캐럴의 『거울나라의 앨리스』(1871)입니다. 영문 인용은 원문을 그대로 쓰고, 한국어 번역은 모델이 직접 옮겼습니다. 번역은 검수가 필요합니다. 〈재버워키〉는 첫 연만 실었고, 나머지 장면 설명은 요약한 서술입니다.

한계

  • 검증 브라우저는 Edge 154(Chromium) 헤드리스 하나였습니다. Safari와 Firefox는 확인하지 않았습니다.
  • 글꼴은 Google Fonts에서 받습니다. 네트워크가 막히면 Batang과 Georgia로 대체됩니다.
  • 3D 변환, clip-path, text-wrap은 최신 브라우저에서 동작합니다. 구형 브라우저 동작은 확인하지 않았습니다.
  • 렌즈는 히어로 내용을 복제해 쓰므로 저사양 기기에서 부하가 있을 수 있습니다. 실제 프레임률은 측정하지 않았습니다.

스크린샷

히어로, 렌즈, 포커스 링 이미지는 보고서 단계에서 같은 파일을 캡처했습니다. 칸 III, 칸 VIII, 모바일 히어로는 페이지 작업의 마지막 실행 스크린샷을 JPEG로 변환했습니다.

측정 방법과 출처

집계 정의

  • 범위. 프롬프트 수신(17행)부터 최종 답변 후 턴 종료(457행)까지입니다. 이 보고서 턴과 그 이전 /model, /effort 설정은 제외했습니다.
  • 중복 제거. 메시지 ID가 같은 기록 줄은 한 호출로 세었습니다. 같은 호출의 사용량은 줄마다 값이 같았습니다(불일치 0건).
  • 토큰. 호출별 input_tokens, cache_creation_input_tokens, cache_read_input_tokens, output_tokens을 합산했습니다. 사고 토큰은 output_tokens_details.thinking_tokens입니다.
  • 시간. 공식 소요 시간은 turn_duration입니다. 사고 시간은 블록별 thinkingDurationMs의 합입니다. 도구 시간은 tool_use 줄과 대응하는 tool_result 줄의 타임스탬프 간격입니다. 기타 시간은 파생값입니다.
  • 미측정. TTFT(첫 토큰까지 시간)는 세션 기록에 없습니다. 가격, 에너지, 페이지 로딩 속도는 토큰이나 시간으로 추정하지 않았습니다.
