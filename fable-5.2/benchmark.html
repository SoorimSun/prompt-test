시간

작업 시간은 50분 31.8초(3,031,834 ms)다. 페이지 작업이 프롬프트 세 개에 걸쳐 진행되어, 세 구간의 작업 시간을 더했다. 내 메시지를 기다린 시간까지 포함한 처음부터 끝까지의 경과 시간은 51분 41.3초(3,101,309 ms)다.

첫 토큰까지 걸린 시간은 미측정이다. Claude Code 세션 로그에 그 값이 기록되지 않는다.

실행 조건과 편차

  • 한 번의 실행으로 기록했다. 다만 로그에는 프롬프트 세 개로 남아 있다. 첫 프롬프트의 응답이 출력 한도에서 멈췄고, 그 뒤 “뭐하고 있니?”와 “이어서 진행해주고…” 두 메시지를 받고 이어서 완성했다. 세 구간을 모두 더했으므로 멈춘 구간의 토큰과 시간도 들어 있다.
  • 프롬프트 전달 방식: 표준 프롬프트를 직접 입력한 것이 아니라 /benchmark-alice-page Fable 5.2 앨리스 벤치 진행해줘로 스킬을 불렀고, 모델이 스킬의 표준 프롬프트를 읽어 폴더 이름만 fable-5.2로 바꿔 수행했다. 그래서 측정값에는 스킬 문서·스크립트·가격표를 읽고 이전 세션 로그의 턴 목록을 살핀 준비 작업이 포함된다.
  • 구간별 실제 작업: 구간 1은 준비와 설계 구상까지였고 페이지 파일은 쓰지 못했다. 구간 2는 폴더 생성, 구간 3에서 페이지 작성과 브라우저 검증을 모두 했다.
  • 도구: 파일 읽기·쓰기·편집, 셸(Bash·PowerShell), Chrome 확장을 통한 브라우저 조작, 헤드리스 Chrome. 하위 에이전트는 쓰지 않았다.
  • 디자인 참고: 다른 모델의 완성 페이지 내용은 열어 보지 않았다. 폴더와 파일 목록만 확인했다.
  • 폴더 이름: 저장소 관례(fable-5.1)에 맞춰 fable-5.2를 썼다. 기록된 모델 ID는 claude-fable-5-2이다.

결과물과 브라우저 확인

looking-glass.html — 49,592바이트, 611줄. SHA-256 7b4a80c21cb627cce79fa69be86931f81c09dd6960cde7db788edb722e4e1d9d

  • 데스크톱 1440×900 (Chrome, 같은 출처 iframe 뷰포트): 히어로부터 결말까지 전 구간을 화면으로 확인. 가로 넘침 없음(문서 폭 1425 = 보이는 폭 1425).
  • 모바일 390×844 (같은 방식): 전 구간 확인. 가로 넘침 없음(375 = 375).
  • 최상위 탭 (창 1707×1803 CSS px): #s5 주소로 진입해 내비가 5번 칸을 가리키는 것과 넘침 없음(1692 = 1692)을 확인. 페이지에서 난 콘솔 오류는 없었고, 기록된 로그와 예외는 브라우저 확장 프로그램의 것이었다.
  • 마우스: 내비 5번 칸 클릭으로 이동, 험프티 덤프티 클릭으로 낱말 뜻 교체, 히어로 클릭.
  • 키보드: Tab으로 “거울 속으로” 링크에 포커스와 테두리 표시, Enter로 첫째 칸 이동, 다음 Tab이 카드 버튼으로 이동, Enter와 스페이스로 카드 뒤집기 상태(aria-pressed) 전환, Enter로 험프티 덤프티 실행.
  • 파일 직접 열기: 헤드리스 Chrome에서 file:// 경로를 1440×900과 390×844로 열어 히어로(WebGL 포함)가 그려지는 것을 확인.
  • 확인하지 못한 것: 동작 줄이기(reduced motion) 설정을 실제로 켠 상태, 오프라인에서의 대체 글꼴 모양, Chrome 외 브라우저. 창 크기 조절 도구가 이 화면에서 동작하지 않아 1440과 390 폭은 iframe으로 재현했다.

토큰 수나 작업 시간으로 전력 사용량이나 페이지 로딩 속도를 추정하지 않았다.
